# Furqan Zaheer Portfolio Design Methodology

## Project Brief

The portfolio presents Furqan Zaheer as an interdisciplinary builder working across biophysics, neural engineering, machine learning, biological systems, software, mathematical modeling, and design culture.

The site should feel like a serious engineering interface crossed with a dark, mythic, research-driven archive. It should not feel like a generic student resume site, SaaS landing page, or soft startup template.

## Brand Positioning

Primary archetype: Engineer-Scholar.

Secondary archetypes: Explorer and Strategist.

Core traits:
- Intellectual intensity
- Technical precision
- Biophysical curiosity
- Dark elegance
- Mythic systems thinking
- Experimental ambition

Positioning statement:

> Furqan Zaheer's portfolio exists at the intersection of biophysics, neural engineering, machine learning, and systems design. It presents a builder who studies living systems not as metaphors, but as engineering problems: signals to decode, structures to model, and patterns to understand.

## Visual Direction

The portfolio should feel like:
- A dark technical research console
- A cinematic engineering archive
- A neural systems dashboard
- A personal intelligence lab
- A mythic interdisciplinary notebook

Avoid:
- Generic white student portfolio layouts
- Pastel startup gradients
- Overly friendly rounded SaaS cards
- Decorative clutter with no informational purpose
- Resume-template energy
- Obvious Roman or Greek text branding

## Color System

Primary palette:
- Deep Black: `#0A0A0A`
- Soft White: `#F5F5F5`
- Muted Gray: `#A1A1AA`
- Vermillion Red: `#E34234`
- Deep Vermillion: `#C2362A`
- Interface Border: `rgba(255,255,255,0.10)`

Black should dominate. Vermillion should read as signal, not decoration. Blue may appear only in technical signal contexts.

## Project Storytelling

Each project should communicate:
- What it is
- Why it matters
- What Furqan built or contributed
- Technical stack
- Metrics, outcomes, or current status
- Visual system or interface preview

Prefer concrete language such as EEG acquisition, feature extraction, motor cortex intent, binary switch output, Notion and Calendar sync, pattern detection, model evaluation, and biopotential signal processing.

Avoid vague language such as "passionate about innovation", "cutting-edge solutions", "leveraging technology", or "changing the world".

Manga / Art:

Mathematics:

## Motion

Motion should be subtle, technical, and purposeful:
- Slow animated grids
- Signal sweeps
- Pulsing nodes
- Data bars
- Hover states
- Carousel transitions
- Neural and biophysical visual accents

Avoid bouncy animations, cartoon transitions, random decorative blobs, and excessive glow.
